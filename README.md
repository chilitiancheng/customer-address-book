# 极简客户地址簿

一个完整可运行的本地客户通讯录系统。第一版只包含客户名称、地址/联系方式、备注三个业务字段，支持新增、编辑、删除、搜索、详情、本地保存、Excel 导入导出、JSON 备份恢复。

## 本地运行

1. 安装 Node.js 18 或更高版本。
2. 在本项目目录打开命令行。
3. 运行：

```bash
npm start
```

4. 浏览器打开：

```text
http://localhost:3000
```

## 局域网访问

在作为服务器的电脑上运行：

```bash
npm start
```

同一局域网内其他电脑访问：

```text
http://服务器电脑IP:3000
```

如果访问不了，请检查 Windows 防火墙是否允许 3000 端口入站。

## 公共访问链接

已部署到 Cloudflare Workers：

```text
https://customer-address-book.customer-address-book-ctc.workers.dev
```

访问时浏览器会弹出用户名和密码：

```text
用户名：admin
密码：KAB-2026-7391
```

公共版本的数据保存在 Cloudflare KV 中，多台电脑打开同一个链接会看到同一份客户数据。

## 数据保存位置

客户数据保存在：

```text
data/customers.json
```

每次保存、导入、恢复前，系统会自动把旧数据备份到：

```text
data/backups/
```

## 如何备份数据

推荐两种方式：

1. 在网页右上角点击“备份”，下载当前 JSON 备份文件。
2. 直接复制整个 `data` 文件夹到 U 盘、网盘或其他电脑。

## 如何恢复数据

在网页右上角点击“恢复”，选择之前下载的 `.json` 备份文件即可。

## Excel 导入导出

- 导入：支持 `.xlsx` / `.xls` / `.csv`。表头建议使用 `客户名称`、`地址/联系方式`、`备注`。
- 导出：点击“导出 Excel”，会生成包含当前全部客户的 `.xlsx` 文件。

## 后期部署建议

这个版本使用 Node 内置 HTTP 服务和 JSON 文件存储，适合小团队、局域网、低维护场景。后续如果多人同时大量录入，可以升级为 SQLite 或 MySQL，但界面和 API 可以基本保留。
